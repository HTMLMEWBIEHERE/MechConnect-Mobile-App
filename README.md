To start this project, follow this instructions:

1. cd backend (make sure to be at the backend structure first)
2. python -m venv venv
3. pip install -r requirements.txt
4. create .env file inside the backend folder (Outdated/Expired Configuration)
5. python manage.py migrate
6. cd frontend-mobile
7. create .env file 
8. npm install
9. npx expo start

This project utilizes 
ReactNative
DjangoFrame Work
PostgreSQL (using supabase)

Project features Map integration with traffic surges, Auto QR code generate, A.I recommendation, Phone number and Email verification auth, Payment using paymongo, and etc.


This project is a joint effort start app created by a 5 team member ViventaLabs.
